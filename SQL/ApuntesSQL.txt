// Condicionales.

/ WHERE <-(Donde (Funciona igual que utilizar un if en c++ solo que si es true devuelve lo buscado))

SELECT * FROM Productos WHERE nombreProducto = 'Banana'; (Busca el producto con el nombre Banana)
Nota: El * lo utilizamos para que a la hora de que encuentre el Producto con el nombre banana, muestre todos los datos de ese producto.

SELECT * FROM Productos WHERE ID_Producto = 18; (Busca el componente con el ID_Producto 18)
SELECT nombreProducto FROM Productos WHERE ID_Producto = 15; (Busca el nombre del producto con su ID_Producto)
Nota: En este caso al encontrar el ID_Producto devuelve solo el nombreProducto vinculado a dicho componente.

SELECT * FROM Productos WHERE Precio <= 70; (Muestra los componentes de todos los productos con un precio <= 70)

/ DELETE <-(Elimina entidades, componentes enteras o una variable en particular del componente)

DELETE FROM Productos WHERE ID_Producto = 18;
Nota: Elimina el producto entero con todos sus componentes ya que verifica que sea el Producto a eliminar mediante ID_Producto = 18.

/ UPDATE <-(Modifica o actualiza el dato o la variable que se quiere cambiar sin eliminar las entidades, componentes o variables)

UPDATE productos SET Precio = 30.5 WHERE ID_Producto = 16;
Nota: Se prepara para actualizar Productos con un nuevo precio ($30.5), luego busca el producto con where para solo actulizar ese producto.

/ AND, OR, NOT

SELECT * FROM Profesor WHERE ID_Carrera = 1 AND ID_Carrera = 3; (Devuelve profesores de 1° año y de 3° año. 
Si no se cumple alguna de las 2 condiciones, no devuelve nada)

SELECT * FROM Profesor WHERE ID_Carrera = 1 OR ID_Carrera = 3; (Devuelve profesores de 1° año o de 3° año.
Si se cumple 1 devuelve solo esa condicion, Si se cumplen ambas condiciones devuelve las 2 y no devuelve ninguno si no existe ninguna)

SELECT * FROM Profesor WHERE NOT ID_Carrera = 1 (Devuelve todos los profesores a exepcion de los que pertenescan a la carrera: ID_Carrera = 1: "Sistemas".)
